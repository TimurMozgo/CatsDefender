# CatsDefender

Лёгкая анимированная игра Cat Defense для браузера и Telegram Mini App.

Играть: https://TimurMozgo.github.io/CatsDefender/

## Запуск

Готовая игра находится в `docs/`. Сборка и установка зависимостей не нужны.
Для локального запуска: `python -m http.server 8080 --directory docs`, затем откройте http://localhost:8080/.

## GitHub Pages

Публикация из ветки `main`, папка `/docs`. Изменения в этой папке публикуются после push.
Для Telegram укажите адрес игры в настройках Mini App вашего бота.
Прогресс хранится в браузере: сохранения с другого адреса сайта автоматически не переносятся.

## Ресурсы

Графика взята из предоставленного набора Craftpix. Происхождение файлов указано в `ASSET-SOURCES.json`, звуков — в `AUDIO-SOURCES.json`. Условия графики: https://craftpix.net/file-licenses/.
Сторонние ресурсы сохраняют собственные условия использования.

## Музыка и звуки

Тихий фон: **8-Bit Battle Loop**, Theodore Kerr / Wolfgang_, CC0 — https://opengameart.org/content/8-bit-battle-loop.
Выстрелы, попадания и интерфейс: **Sci-Fi Sounds**, Kenney, CC0 — https://opengameart.org/content/sci-fi-sounds.
Оригинальные файлы перекодированы в MP3 и выровнены по громкости. Синтеза и генерации звука нет. Полный перечень исходников — AUDIO-SOURCES.json.
Музыка включается после нажатия и только в бою; при выстрелах приглушается, на паузе/в магазине/при сворачивании останавливается. Общая кнопка звука отключает и музыку, и эффекты. Предоставленные пользователем победа, поражение и удар по баррикаде сохранены.
